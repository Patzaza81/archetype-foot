Lancer ton propre rejeu

Le rejeu s’exécute sur GitHub Actions à partir des archives du dépôt. Tu peux modifier le support minimal de validation et la borne haute ; le moteur refusera toute borne basse inférieure à 10.

Ouvrir le test Football-Data Ouvrir le test Beat The Bookie Consulter le code et les tests du moteur
  1. Dans GitHub Actions, ouvrir le workflow puis toucher Run workflow.
  2. Conserver la cote minimale à 10. Le moteur bloque toute valeur inférieure.
  3. Lancer le workflow et attendre sa fin.
  4. Ouvrir le run terminé, puis télécharger l’artefact de rapport pour consulter les résultats détaillés.

Comment lire les résultats

  • Taux de réussite : part des sélections gagnantes ; il doit être comparé au seuil de rentabilité correspondant à la cote moyenne.
  • ROI : résultat comptable à mise constante d’une unité, avant commissions et contraintes de liquidité.
  • Test chronologique : période tenue à l’écart du réglage des paramètres et des seuils.
  • Limite majeure : les archives historiques n’ont pas toutes l’heure exacte de capture des cotes ; elles ne prouvent donc pas qu’un prix était réellement disponible au moment du pari.

Conclusion actuelle : le moteur fonctionne techniquement, mais les deux archives ne démontrent pas encore une rentabilité reproductible. Le résultat positif de Football-Data (+3,35 %) n’est pas confirmé par Beat The Bookie (−2,03 %). Aucun pari ne doit être considéré comme validé.
